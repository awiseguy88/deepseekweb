// 07 / STRAIGHT ANSWERS

Before you
hand it over.

Powerful systems should be understandable. Especially when they can touch real work.

Is this more than a chatbot?

WiseAI is an agent workspace built around files, tools, sessions and task execution. The exact real-world actions available depend on the harness and configured integrations.

Does the laptop demo actually work?

Yes, within its browser sandbox: you can execute guided demo workflows, create and edit files, use limited commands and download artifacts. It does not call a live AI model or operate your actual device.

Can WiseAI connect to other computers?

Computer control requires compatible remote-access tooling, user authorization and proper isolation. A public web page cannot safely or silently control a visitor's computer.

Can it send emails, texts or make calls?

Those workflows depend on configured providers, the correct permissions and appropriate approval steps. Check which integrations are enabled in the live workspace.

Can it keep working when I close the tab?

That requires an active cloud runtime and a job scheduler in the live deployment. The website sandbox is temporary and only runs while the page is open.

Are these the real subscription prices?

Not yet. They are proposed examples for the design. Live plan availability, pricing and usage limits should be finalized before customers can purchase anything.
